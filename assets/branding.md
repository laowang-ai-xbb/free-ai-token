## Sync discipline (when to update this file)

Update this file BEFORE the corresponding release, when any of these
change:

1. Repository URL (move, fork, mirror).
2. Author handle / social handle (rebrand).
3. License type.
4. Skill display name (`display_name` in `SKILL.md` frontmatter).

After updating this file:

1. Sync the matching i18n strings in `references/i18n/zh.json` and
   `en.json` (the wording carries the author / repo name in user-facing
   text).
2. Sync the README author sections (`README.md` + `README.zh-CN.md`) —
   they MUST show the same `{{repo_url}}` and the same author handle.
3. If the change is user-visible (new repo, new handle, rebrand), add a
   `CHANGELOG.md` line under the next version's section.

## What this file is NOT

- Not a license file. The license lives in `LICENSE` (MIT, full text).
- Not the README. The README is the public-facing intro; this file is
  the **internal** contract that the output fills from.
- Not a copy of `SKILL.md` frontmatter. The skill's `version` and
  `display_name` are authoritative from `SKILL.md`; this file only mirrors
  them for the output rendering.
